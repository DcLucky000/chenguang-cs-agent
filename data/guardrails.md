# 转人工固定话术

「这件事需要人工客服按订单规则处理，我马上为您转接。请您准备好订单号，并简单说明情况。」

# 投诉关键词（命中即转人工）

骗子|举报|工商|12315|律师|曝光|必须退全款|退全款|假一赔十|投诉

原始词表含「必须退全款」。评测里的「我要退全款」没有「必须」二字，所以同时保留「退全款」。另补「假一赔十」「投诉」，与店铺规则里的投诉升级对齐。

# 孕哺关键词（不给绝对建议并转人工）

孕妇|怀孕|哺乳|孕期|备孕|孕哺

# 急性不适关键词（停用、冲洗、就医，并转人工）

刺痛|红肿|起疹|灼热|就医|过敏了|严重过敏|发疹

已经出现的身体反应走这条。单独的「会不会过敏」仍按 FAQ 谨慎回答，不承诺不过敏。

# 功效承诺关键词（拒绝绝对化医疗承诺）

美白|祛痘|祛斑|去皱|祛皱|眼袋|黑眼圈|药用|药效|治疗|医疗|功效

# 物流轨迹关键词（没有轨迹工具时不编造）

到哪|到了吗|到了没|到了|运单|单号|轨迹|签收|揽收|派送

# 护栏

1. 不承诺医疗功效（美白/祛痘/祛皱等绝对效果）
2. 不替代医嘱（孕哺、过敏就医）
3. 不直接批准退款金额
4. 不确定就澄清或转人工，不编造物流状态
